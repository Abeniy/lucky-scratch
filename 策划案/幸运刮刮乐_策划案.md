## 1. 游戏概述

### 1.1 一句话定位

用得分购买不同面值的刮刮卡，用鼠标刮开九宫格揭晓图案赚取得分；得分达到阈值即永久升级，解锁更高面值、更高风险的卡片和刮具，每次升级三选一获得肉鸽式增益；刮出炸弹可能把得分打成负数而破产。攒得分、控风险、滚雪球。

### 1.2 基本信息

| 项 | 内容 |
|---|---|
| 类型 | 单机 · 休闲博彩 · Roguelike 成长 |
| 视角 / 方向 | 2D，PC 横屏，鼠标操作 + 键盘快捷键 |
| 单局时长 | 每张卡 5~15 秒，无局数上限，可无限续玩 |
| 存档 | 浏览器 `localStorage`，自动存档 |
| 美术风格 | **手绘彩铅 / 蜡笔质感**的卡面与图标，放在**木纹桌面**背景上，桌面散落贴纸、星星、硬币；UI 底板为**纸片拼贴 / 撕纸 / 网点**风格（黄纸带、米白纸、黑色笔刷、橙色网点横幅） |
| 主色 | 暖木棕背景，金黄 `#ffc42e` 得分与进度，米白纸片 `rgba(255,250,236,.92)` 状态条，墨棕文字 `#6b5335` |

### 1.3 核心爽点

1. **刮开的触感**：连续、无断点的刮痕；刮开一格立刻弹出图案。
2. **即时反馈**：凑成奖励的瞬间在卡上飘出「+金额」，刮到炸弹立刻「炸弹！」+ 震屏。
3. **分级狂欢**：按中奖大小 5 级全屏特效，巨奖有 JACKPOT 横幅、光柱、彩纸、连震。
4. **成长决策**：升级三选一增益 + 刮具搭配，改变每张卡的期望收益。

## 2. 核心循环

```
开局（读档；首次进入赠送一张免费铜板卡）
  ↓
底部购卡区选卡 → 扣得分 → 发牌（卡片滑入）
  ↓
鼠标按住在九宫格上刮 → 单格刮开 60% 即揭晓该格（即时正/负反馈）
  ↓
9 格全部揭晓 → 自动结算：判奖 → 叠加刮具与增益 → 得分变化 → 结算浮层 + 分级特效
  ├─ 得分 ≥ 下一级阈值 → 升级（可连升）→ 解锁新卡 / 新刮具
  │      → 依次弹出「获得新刮具」弹窗 → 「三选一增益」弹窗（每升 1 级 1 次）
  ├─ 得分 < 0 → 护身符免死（得分归 50）或 破产（得分归 50，等级/刮具/增益保留）
  └─ 继续购买下一张
```

- 等级**永久保留**，得分回落不会降级。
- 破产**不清档**：只把得分重置为 50、连击清零，破产次数 +1。

## 3. 数值系统

### 3.1 初始状态与存档

存档键：`lucky-scratch`（localStorage，JSON）

```json
{
  "coins": 100,
  "level": 1,
  "unlockedCards": ["copper"],
  "ownedTools": ["coin"],
  "equippedTool": "coin",
  "perks": [],
  "combo": 0,
  "burstEnergy": 0,
  "stats": { "maxCoins": 100, "biggestJackpot": 0, "totalScratches": 0, "bankruptcies": 0 }
}
```

- `perks` 是增益 id 数组，同一 id 出现 N 次 = N 层。
- 每次状态变化后立即存档。读档时与默认档合并（缺字段补默认值），过滤掉未知增益 id。

### 3.2 等级

```
LEVEL_THRESHOLDS = [0, 250, 700, 1800, 4500, 10000, 26000, 65000]   // 索引 i = 升到 Lv.(i+1) 所需得分
MAX_LEVEL = 8
```

| 等级 | 达到得分 | 解锁卡片 | 解锁刮具 |
|---|---|---|---|
| Lv.1 | 初始 | 铜板卡 | 硬币 |
| Lv.2 | 250 | 果园卡 | 贝壳 |
| Lv.3 | 700 | 矿洞卡 | 四叶草 |
| Lv.4 | 1800 | 赌城卡 | 水晶球 |
| Lv.5 | 4500 | 星海卡 | 钻头 |
| Lv.6 | 10000 | 时空卡 | — |
| Lv.7 | 26000 | — | — |
| Lv.8（MAX） | 65000 | — | — |

- 升级判定：`while (level < 8 && coins >= THRESHOLDS[level]) level++`，可一次连升多级，每升 1 级获得 1 次三选一。
- 进度条：`percent = (coins − THRESHOLDS[level−1]) / (THRESHOLDS[level] − THRESHOLDS[level−1])`，夹在 0~100%。
- 提示文字：`距下一级 N`（N = 阈值 − coins，最小 0）；满级显示 `MAX`，进度条 100%。

### 3.4 刮具（右侧栏，佩戴 1 件，持久拥有）

| 序号/快捷键 | id | 名称 | 副标题 | 获取 | 效果（说明文案） |
|---|---|---|---|---|---|
| 1 | coin | 硬币 | 保底 | 初始拥有 | 揭晓后额外返还本卡最高单格估值（封顶卡价 50%） |
| 2 | shell | 贝壳 | 幸运 | Lv.2 | 好符号权重 +15%，💣/黑洞 -30% |
| 3 | clover | 四叶草 | 护身 | Lv.3 | 每张卡开刮前自动移除 1 个 💣/黑洞 |
| 4 | crystal | 水晶球 | 透视 | Lv.4 | 发牌时预先揭示中央格 |
| 5 | drill | 钻头 | 暴富 | Lv.5 | 矿洞 / 赌城中奖 +25%，但 💣 伤害 +25% |

效果实现细节：

- **硬币**：单格估值 = match 卡 `赔付/3`；collect 卡（好符号）`大奖/9`；lines/twin 卡 `连线赔付/3`。取本卡 9 格中出现过的符号的最大估值，`min(round(最大估值), round(原价×0.5))`。与是否中奖无关，例如：铜板卡出现红包 → 40 封顶为 5；矿洞出现任一矿石 → 50 封顶为 30；果园出现任一水果 → round(12.4)=12；星海出现恒星/星星/星云 → 封顶 200。
- **贝壳**：发牌抽符号时，坏符号（`danger: true`）权重 ×0.7，其余 ×1.15。**对时空卡同样生效**：雷击权重 ×0.7，卡面 A 与平行时间线 B 都使用倾斜后的权重。
- **四叶草**：发牌后把第一个坏符号（按索引顺序）替换为随机好符号，仅 1 个。只处理果园枯叶、矿洞/赌城炸弹、星海黑洞；**对时空卡无效，不移除雷击**（原版四叶草读取 `prize.bad`，时空卡的坏符号定义在 `prize.base.bad`）。
- **水晶球**：发牌时格子 4（正中）直接揭晓，不触发即时反馈。
- **钻头**：仅对矿洞卡、赌城卡生效：奖金 ×1.25（奖金>0 时），固定罚金 ×1.25。

切换规则：
- 已拥有 → 点击即佩戴，显示刮具说明气泡（§5.5）。
- 台上的卡**已经刮开过任意格**（水晶球预揭格不算）→ 拒绝切换，提示「台上这张已经开刮了，刮完再换刮具吧」。
- 台上的卡**还没刮** → 允许切换，并用新刮具对同一种卡**免费重新发牌**（保留原花费）。
- 未拥有（等级锁）→ 提示「刮具「X」需升到 Lv.N 解锁」。

### 3.5 增益（升级三选一，永久，可叠加）

| id | 名称 | 说明文案（界面原文） | 计算 |
|---|---|---|---|
| fortune | 财源广进 | 所有中奖金额 +12%（可叠加） | 奖金 ×(1 + 0.12×层) |
| thrifty | 精打细算 | 购卡价 -8%，最多 -50% | 价格 = max(1, round(原价×(1 − min(0.5, 0.08×层)))) |
| safety | 稳健保底 | 每张卡返还成本 ×25%，最多 100% | 返还 round(min(1, 0.25×层) × 原价) |
| jackpot2 | 一夜暴富 | 中奖时 8% 概率金额 ×2（概率叠加） | 概率 min(0.6, 0.08×层)，命中奖金 ×2 |
| firstDouble | 首刮双倍 | 储存 1 次双倍机会；下一次中奖金额 ×2，未中奖不消耗 | 中奖时奖金 ×2，并**消耗 1 层** |
| amulet | 护身符 | 破产免死 1 次（金币归 50），可叠加 | 得分<0 时消耗 1 层，得分=50 |
| combo | 连击大师 | 连中 3 次后奖金 ×1.5，断连失效 | 本张之前已连中 ≥3 且本张中奖 → ×1.5 |
| treasure | 鉴宝之眼 | 矿石 / 水果类中奖额 +20%（可叠加） | 仅 collect 卡：奖金 ×(1 + 0.2×层) |
| burst | 爆奖蓄能 | 未中奖蓄能 +10%，每层额外 +5%；中奖时释放加成，最高 +50% | 见 §3.6 第 9 步 |
| rebate | 幸运加刮 | 结算后 20% 概率返还本张卡价；每层 +8%，最高 60% | 概率 min(0.6, 0.2 + 0.08×(层−1))，返还原价 |

三选一规则：从 10 个增益中**随机不重复抽 3 个**（已拥有的也可以出现，卡片标题后显示 `x层数`），点击即获得。

### 3.6 结算公式（严格按顺序）

```
base = judge(卡, 9格符号)        // 得到 gross 奖金、penalty 固定罚金、jackpot 最大单项、win=gross>0、dangerCount 坏符号数
1. gross, penalty = base
2. 钻头 且 卡∈{矿洞,赌城}：gross>0 时 gross×=1.25；penalty×=1.25
3. 若 gross>0：
     gross ×= (1 + 0.12×财源广进层)
     若 collect 卡：gross ×= (1 + 0.2×鉴宝之眼层)
     若 burstEnergy>0：gross ×= (1 + min(0.5, burstEnergy))
     若 有连击大师 且 combo≥3：gross ×= 1.5
     若 有首刮双倍：gross ×= 2（之后消耗 1 层）
4. 若 gross>0：以 min(0.6, 0.08×一夜暴富层) 概率 gross ×= 2
5. gross、penalty 四舍五入
6. 百分比罚金（仅时空卡）：coinPct = round(当前余额 × 0.12 × 雷击数)
7. 硬币保底 coinBonus（佩戴硬币时）
8. 稳健保底 back
9. 幸运加刮 rebate（概率返还原价）
net = gross − penalty − coinPct + back + coinBonus + rebate
coins += net

之后：
- totalScratches +1；biggestJackpot = max(原值, base.jackpot)
- combo = win ? combo+1 : 0
- 爆奖蓄能（有该增益时）：win → burstEnergy = 0；否则 burstEnergy = min(0.5, burstEnergy + 0.10 + 0.05×(层−1))
- maxCoins 更新 → 升级判定
- coins < 0：有护身符 → 消耗 1 层，coins=50（免死）；否则破产：bankruptcies+1，coins=50，combo=0
- 存档 → 刷新界面 → 结算浮层/特效 → 刮具解锁弹窗队列 → 三选一队列
```

> 注意：第 3 步「是否中奖」按 base.gross>0 判断；稳健保底、硬币保底、幸运加刮的「卡价」均用**原价**。

### 3.7 购卡规则

- 点击已解锁卡槽 → 购买并发牌；扣 `折后价`。
- 台上有**已刮开**的未结算卡 → 拒绝：「台上这张已经开刮了，先刮完再换别的吧」。
- 台上有**未刮开**的卡、点的是同一种卡 → 拒绝：「「X」正在台上，刮开它试试~」。
- 台上有**未刮开**的另一种卡 → 允许换卡：先退还旧卡花费，再扣新卡价格（余额 + 退款 ≥ 新价格才行）。
- 余额不足：「金币不足，买不起「X」（需 N）」。
- 未解锁卡槽：灰暗不可点。
- 开局（每次刷新页面）自动在台上发一张**免费**铜板卡。

### 4.1 刮的过程中的即时反馈

- **正反馈**：每揭晓一格，按「已揭晓的格子」计算当前已锁定的奖金（按符号分组，单调递增）：
  - match：已揭晓中每种符号满 3 个的组数 × 赔付；
  - collect：9 格全揭晓且无坏符号 → 大奖；否则最多同种 n≥3 的档位；
  - lines：只统计**全部格子都已揭晓**的线。
  - 某符号锁定额比上次大 → 在卡上飘出 `[符号图] +增量`：金黄渐变斜体 42px，位置在卡片高度 44% / 55% / 66% 轮流错开，显示 950ms。
- **负反馈**：揭晓到坏符号 → 飘出 `[符号图] 炸弹！`（用符号名称：枯叶！/炸弹！/黑洞！）：暗红渐变斜体 38px，位置 72% / 82% / 92% 轮流，950ms；同时轻震屏（7px，240ms）。**时空卡刮到雷击没有即时飘字和震动**，雷击只在结算时按余额扣分（原因同四叶草）。

## 6. 自适应规则

页面**不做响应式重排，也没有整体逻辑画布**（不要建立 1280×720 之类的设计画布再整体缩放）。顶栏、增益条、状态条、调试按钮按真实视口像素 fixed 定位且不缩放；只有舞台单元和刮具栏分别等比缩放，**最大 1 倍**——窗口足够大时卡片就是原尺寸 800×800（缩放用 `transform: scale`，原点为中心；刮卡坐标必须用 `getBoundingClientRect` 换算，保证缩放后刮的位置准确）：

```
topOcc  = max(顶栏底边, 增益条底边)          // 无增益约 110，有增益约 170
botOcc  = 视口高 − 状态条顶边
availH  = max(120, 视口高 − topOcc − botOcc − 32)
safeCenter = (topOcc + (视口高 − botOcc)) / 2

刮具栏：k_t = min(1, availH/592, 视口宽×0.28/128)
        top = safeCenter − 592/2；transform: scale(k_t)

舞台：  reserve = min(128×k_t + 50 + 24, 视口宽×0.28)       // 左右对称预留，卡片永不压到刮具栏
        availW  = max(160, 视口宽 − 2×reserve)
        k_s = min(1, availH/952, availW/920)
        transform: translateY((topOcc − botOcc)/2) scale(k_s)
```

- 窗口 resize、增益条高度变化时重新计算。
- 窄屏（视口宽 ≤ 720）：hud-side 下限降为 128，「得分：」20px、数字 28px。
- 震屏特效必须**叠加**在舞台的 transform 之上，结束后恢复，不能清空。

## 9. 美术资源规范（换素材的依据）

### 9.1 风格指南

- **卡面**：手绘彩铅 / 蜡笔质感，饱和暖色，粗描边；每张卡上方或左侧有手写大标题（小铜运 / 摘果子 / 挖矿吧 / 梭哈 / 星想事成 / 时来运转）；**必须画出 3×3 的格子框**（米白色方格或圆格），并在格子外留出一块空白区放「中奖要求」说明。
- **符号**：同风格彩铅图标，正方形透明底，主体居中、四周留约 8% 边距。
- **UI 底板**：纸片拼贴 / 撕纸边 / 网点 / 笔刷，黄、米白、黑、橙四色为主。
- **刮具图标**：米黄色单色线稿图标，透明底（放在米黄圆环框里）。
- **增益图标**：彩色手绘插画，透明底，主体饱满。
- 所有带透明区域的素材**必须是带 Alpha 的 PNG**；背景图可用 JPG。

### 9.2 资源注册表（代码约定）

```js
// 唯一的图片入口：资源 ID → 文件路径（或 data URI）。换素材 = 改这里的值。
const ASSETS = {
  'bg.table': 'assets/bg.jpg',
  'card.copper.face': 'assets/cards/copper.png',
  // ……按 §9.3 全部列出
};
// 读取：为空或加载失败时返回 null，调用方使用占位（§9.4）
function asset(id) { return ASSETS[id] || null; }
```

- CSS 背景图也必须由 JS 根据 `ASSETS` 注入（例如设置 CSS 变量 `--asset-bg-table: url(...)`），不在 CSS 里写死路径。
- 换素材时：用户会说「把 `card.mine.face` 换成 xxx.png」，Agent 只需修改 `ASSETS` 对应项；若换的是卡面/涂层，再按 §9.5 校准几何。

#### G. 字体（使用平台内置 MainFont）

Gamex 平台提供 `MainFont`、`Farn`、`Arcade_Pixel` 三种字体。本游戏**全部文字只用 `MainFont`**，资源包不再附带字体文件。

| 资源 ID | 字体 | 用途 |
|---|---|---|
| font.main | `MainFont`（平台内置） | 全局所有文字：得分、等级、卡内说明、卡槽、刮具气泡、状态条、弹窗、结算浮层、飘字、JACKPOT 横幅、调试面板 |

原版源码里的字体名按下表替换，其余样式一律不动：

| 原版写法 | 替换为 |
|---|---|
| `font-family: "FZLTRegular", "FZLTHeavy", "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif;`（全局） | `font-family: "MainFont", sans-serif;` |
| `font-family: "FZLTRegular", "FZLTHeavy", sans-serif;`（6 张卡的说明区） | `font-family: "MainFont", sans-serif;` |
| `@font-face` 中的 FZLTRegular / FZLTHeavy / FarnModern 声明 | 删除，不加载 |
| 刮卡光标、涂层占位文字等 Canvas 内文字 | 同样使用 `MainFont` |

- 字号、字重（400/600/700/800/900）、斜体、颜色、字距、阴影全部按原版保留，不因换字体而调整。
- **不使用** `Farn`、`Arcade_Pixel`。
- 截图验收前必须等字体加载完成（`document.fonts.ready`）。
- 原版参考截图是用方正兰亭黑渲染的。换成 MainFont 后文字宽度可能不同，连带得分控件宽度、等级区宽度（由得分控件宽度推算）一起变化。比对时：文字本身的字形、宽度允许不同，但字号、字重、颜色、对齐方式、文字框位置必须一致；等级区宽度按 `视口宽 − 40 − 2×max(140, 得分控件实测宽 + 24)`（上限 980）核对；不依赖文字宽度的元素（卡片、舞台、刮具栏、状态条、增益条、弹窗框体）仍按 2px 标准。

### 9.4 占位规则（阶段 1 使用）

1. 占位图的**显示尺寸、位置、层级与正式素材完全相同**，只是内容换成 emoji / 色块 / 渐变。
2. 卡面占位必须在 `scratchGrid` 位置画出 9 个格子、在 `inlineInfo` 位置留出说明区，保证刮卡与判奖可完整测试。
3. 符号占位：用表 C 的 emoji，字号 = 格宽 × 0.62。
4. 占位与正式素材通过同一套 `asset(id)` 判断切换，不允许出现两套布局。

### 9.5 卡面几何数据（`CARD_GEOMETRY`）

所有值为**相对卡面宽高的比例（0~1）**，以卡面左上角为原点。

```js
const CARD_GEOMETRY = {
  copper:    { scratchGrid: { x: 0.494,  y: 0.3831, w: 0.4087, h: 0.4051 },
               coatGrid:    { x: 0.494,  y: 0.3831, w: 0.4087, h: 0.4051 } },
  orchard:   { scratchGrid: { x: 0.2953, y: 0.2578, w: 0.4105, h: 0.3908 },
               coatGrid:    { x: 0.2953, y: 0.2578, w: 0.4105, h: 0.3908 } },
  mine:      { scratchGrid: { x: 0.5009, y: 0.3324, w: 0.388,  h: 0.3833 },
               coatGrid:    { x: 0.5006, y: 0.3297, w: 0.389,  h: 0.3872 } },
  casino:    { scratchGrid: { x: 0.2535, y: 0.3329, w: 0.4811, h: 0.4319 },
               coatGrid:    { x: 0.2535, y: 0.3329, w: 0.4811, h: 0.4319 } },
  star:      { scratchGrid: { x: 0.5341, y: 0.3492, w: 0.3508, h: 0.3454 },
               coatGrid:    { x: 0.5338, y: 0.3477, w: 0.3513, h: 0.3467 } },
  spacetime: { scratchGrid: { x: 0.2652, y: 0.2603, w: 0.4696, h: 0.455 },
               coatGrid:    { x: 0.2664, y: 0.2591, w: 0.4684, h: 0.4574 } },
};
// inlineInfo（说明区）见 §5.4 表格，同样放进 CARD_GEOMETRY[id].inlineInfo
```

- `scratchGrid`：**卡面图**上九宫格外框的位置 → 决定符号格子与刮擦判定区域。
- `coatGrid`：**涂层图**上 9 个灰块外框在涂层图中的位置。
- 涂层绘制：把涂层图缩放 `kx = sg.w/cg.w, ky = sg.h/cg.h`，绘制尺寸 `(W×kx, H×ky)`，偏移 `dx = sg.x×W − cg.x×W×kx`，`dy = sg.y×H − cg.y×H×ky`（W、H 为刮擦画布尺寸）。这样涂层图的九宫格精确盖在卡面九宫格上。
- **换卡面/涂层后的校准方法**：在新图里量出九宫格外框（左上角 x、y 与宽高，除以图片宽高得到比例），写入上表；或使用调试面板的网格校准模式（§7.6）。

### 9.6 素材替换流程（阶段 2）

1. 按《素材上传清单.md》把 73 张单独上传的图片放回 §9.3「文件」列对应路径，素材**原样使用**，不得生成、重绘、调色、裁切、改名或替换。
2. Agent 把 `ASSETS` 中各资源 ID 指向对应文件，全部文字使用平台 `MainFont`（§9.3 G）；最终画面不得残留任何占位。
3. 对照参考截图逐项检查：卡面九宫格与涂层是否重合、说明区是否落在留白处、弹窗分区是否与底图色带对齐；不齐则只调整 `CARD_GEOMETRY` 或对应元素的位置参数，**不改素材、不改玩法数值**。
4. 之后单张替换：用户说「把 `资源ID` 换成 新文件」，只改该项；若新图比例与 §9.3 不同，按该表「替换约束」同步调整。

## 10. 验收清单

**玩法与数值**
1. 新档：得分 100、Lv.1、仅铜板卡可买、刮具仅硬币；台上自动有一张免费铜板卡。
2. 铜板卡说明区概率依次显示 45.0% / 35.0% / 18.0% / 2.0%。
3. 得分达到 250 → Lv.2：解锁果园卡与贝壳，先弹「获得新刮具」，关闭后弹三选一。
4. 一次结算跨越多个等级时，三选一按等级数连续弹出。
5. 精打细算 1 层时铜板卡价格显示 9（round(10×0.92)）。
6. 得分被罚成负数：有护身符 → 得分 50 且护身符层数 −1；无 → 破产，得分 50，等级/刮具/增益保留。
7. 时空卡雷击按当前余额 12%/枚扣除。

**交互**
8. 快速划动刮痕连续不断；单格刮开 ≥60% 即弹出符号；9 格全开自动结算。
9. 刮的过程中凑成奖励立刻飘「+金额」；刮到枯叶/炸弹/黑洞立刻飘对应名称并轻震；**刮到时空雷击不飘字、不震动**，只在结算扣分。
10. 已开刮时不能换卡、不能换刮具；未开刮时换刮具会免费重发同种卡。
11. A/D 翻页、1~5 切换刮具有效；弹窗打开时 A/D 无效。
12. 悬停增益徽章显示说明气泡；三选一卡片悬浮上浮并发橙黄光。
13. 四叶草对时空卡无效；贝壳对时空卡有效。

**布局与像素比对**
14. 主验收视口（用户全屏窗口，如 2560×1290）：舞台与刮具栏缩放均为 1，卡片 800×800。1600×1000：舞台 0.84、刮具栏 1；1280×720：0.546219 / 0.878378。
15. 任意视口得分与等级区不重叠、卡片不压刮具栏、舞台底不压状态条；HUD 不随舞台缩放。
16. 结算与震屏结束后舞台位置/大小与之前完全一致。
17. 弹窗打开时顶栏与状态条不被遮罩压暗。
18. `MainFont` 加载完成后，在相同视口、相同存档状态下与原版参考截图逐张叠图比对：元素位置偏差 ≤ 2px，颜色、字号、字重一致（随机内容如三选一抽到的增益除外；因字体不同造成的字形与文字宽度差异按 §9.3 G 口径处理）。

**美术与可替换性**
19. 最终画面只使用资源包中的原版素材，全部文字为 `MainFont`，无占位残留。
20. 清空 `ASSETS` 中任意一项，游戏不报错，对应位置显示占位。
21. 只改 `ASSETS` 某一项即可完成该素材替换；全局搜索代码，除 `ASSETS` 外不存在图片路径。
