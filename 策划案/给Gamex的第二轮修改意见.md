## 一、阻塞问题：Phaser 与像素级复刻的矛盾

**现状**：`00 §2、§3` 保留 Phaser，同时又要求复刻"浏览器文字表现、滤镜、混合定位、布局、底图拉伸、按键斜切与全部关键帧节奏"。这两者在**纯 Phaser 渲染**下互相矛盾：Phaser 的 Text / Image 无法得到与浏览器 CSS 一致的字形排版、`filter: drop-shadow / grayscale`、`calc()` 百分比定位、`skewX`、`text-overflow: ellipsis`、flex/grid 布局等结果。

**解决方式**：运行目标不变，仍是 Phaser 项目，但界面用 Phaser 自带的 **DOM 元素能力**承载，原版 HTML/CSS 直接复用：

```js
new Phaser.Game({
  type: Phaser.AUTO,
  parent: 'game-root',
  transparent: true,
  scale: { mode: Phaser.Scale.RESIZE },     // 跟随真实视口，不建立逻辑画布、不 letterbox
  dom: { createContainer: true },           // 开启 DOM 叠加层
  scene: [MainScene],
});
```

| 部分 | 实现方式 |
|---|---|
| 背景、顶栏、增益条、舞台（卡面 + 说明区 + 购卡区）、刮具栏、状态条、弹窗、调试面板、结算浮层、飘字、JACKPOT 横幅 | **DOM 元素**（`this.add.dom()` 或直接挂在 DOM 容器里），**结构、类名、样式直接沿用原版 `index.html` / `style.css`** |
| 刮卡涂层 | DOM 中的 `<canvas>`，用 Canvas 2D 的 `destination-out` 擦除（与原版一致），坐标用 `getBoundingClientRect` 换算 |
| 舞台 / 刮具栏缩放、震屏 | 对 DOM 元素写 `transform`，公式按 `01 §6` |
| Phaser 本身 | 负责启动、场景生命周期、resize 事件；彩纸、光柱等全屏特效**也按原版用 DOM + CSS 动画**，不要改成 Phaser 粒子（颜色、尺寸、轨迹会变） |

**修改**：
- `00 §2` 改为："运行目标：Phaser（`Scale.RESIZE` + `dom.createContainer`）。所有界面以 DOM 叠加层实现并复用原版 HTML/CSS，刮卡涂层为 DOM 内 Canvas 2D。"
- `00 §3` 删除"这是唯一不采纳的目标变更"，改为上面这一句。
- `01 §4` 第一行"九宫格符号是 DOM（图片），上面盖一层同尺寸 Canvas"保持不变（与这个方案一致）。

> 如果 Gamex 平台不允许使用 DOM 叠加层，请直接告知，我们再评估是否改为原生 HTML 项目，或者接受哪些区域放宽验收。
