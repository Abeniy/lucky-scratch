## 一、根本性偏差（必须改，否则无法像素级一致）

### 1. 运行目标：Phaser → 原生 HTML/CSS/Canvas

**问题**：`00 §2、§3` 把运行目标定为 Phaser，并写了"实现方式以稳定复现业务效果为准，不在策划阶段绑定代码组织"。

**为什么不行**：原版视觉大量依赖浏览器 CSS 的渲染结果，Phaser（WebGL/Canvas 绘制）无法逐像素一致：

| 原版依赖的 CSS 能力 | 例子 |
|---|---|
| 浏览器文字排版与字体渲染 | 所有中文文案、得分数字斜体、字间距、单行省略 `…` |
| `filter: drop-shadow / grayscale / brightness` | 得分数字双层橙光、未解锁卡槽变灰、三选一卡片悬浮发光 |
| `calc()` 百分比 + px 混合定位 | 卡内说明区 `left: calc(10.5% + 30px)` |
| flex / grid 布局 | 顶栏三列栅格、说明区两列、购卡区 |
| `background-size: 100% 100%` 拉伸底图 | 状态气泡、结算横幅随文字伸缩 |
| `transform: skewX(-11.3deg)` | A/D、1~5 按键字母倾斜 |
| CSS keyframes 动画 | `symPop / resultPop / fxBanner / cardSwapIn/Out` |

**修改**：
- `00 §2`："运行目标：Phaser" → "运行目标：浏览器原生 HTML + CSS + JavaScript（无框架），刮卡涂层用 Canvas 2D"。
- `00 §3` 整节改为："技术栈与原版一致。以附件原版源码为基础实现（可直接沿用其 DOM 结构、CSS 类名与样式），验收标准是与参考截图像素一致。"
- `01` 文件头"原案对单文件、原生技术…只作为行为结果参考，不覆盖当前运行目标"一句**删除**。

### 2. 删除"1280×720 逻辑视口"

**问题**：`00 §2`、`01` 文件头写"采用 1280×720 逻辑视口；1600×1000 是自然尺寸布局参考"。

**原版实际**：**没有逻辑画布，也没有整体缩放或 letterbox**。
- 顶栏、增益条、状态条、调试按钮：按**真实视口像素**用 `position: fixed` 定位，**不缩放**。
- 只有两块会缩放：舞台单元（卡片 + 购卡区，自然尺寸 920×952）和刮具栏（自然尺寸 128×592），按 `01 §6` 的公式分别计算缩放系数。
- 1600×1000、1258×900 等是**验收用视口**，不是"自然尺寸布局参考"。

如果做成 1280×720 画布再整体缩放，到 1600×1000 时顶栏文字会被放大 1.25 倍，与原版不符。

**修改**：
- `00 §2` "逻辑视口：1280×720" → "无逻辑画布；HUD 按真实视口像素 fixed 布局，舞台与刮具栏按 01 §6 公式独立缩放。主验收视口为 1280×720 与 1600×1000。"
- `01` 文件头同步改。
- 在 `01 §6` 的验收参考表中补充 1280×720 的实测值（见第四部分）。

### 3. 美术：必须用原版素材，禁止自绘或再诠释

**问题**：
- `00 §7`："没有外部素材时，也要按既定风格制作并接入完整正式视觉，不能把几何占位作为最终画面。"
- `00 §6` 写了一整套美术方向（危险图案"更暗或更尖锐的轮廓"、标题"手写海报感"等），这是给画师的生成指导，会诱导 Agent 重绘素材。

**修改**：
- `00 §7` 第 2 点改为："正式素材**只能**使用用户提供的《美术资源包.zip》（73 个文件，路径与 01 §9.3 一致），**禁止 AI 生成、重绘、调色、裁切或替换**。素材包已提供，不存在'没有外部素材'的情况。阶段 1 的占位仅用于开发调试，阶段 2 必须全部换成原版素材。"
- `00 §6`"画面与美术方向"整节改为："画面以原版素材与参考截图为准，不做风格再诠释。"
- 后续换素材仍按 `01 §9` 的资源 ID 机制执行（这部分理解正确，保留）。

### 4. 字体：不得改变字形表现

**问题**：`00 §6` 写"标题、得分和大额奖励用更粗、更斜、更有手写海报感的表现"。

**原版实际**：只有得分数字是 36px / 900 / 斜体，其他文字严格按 `01 §3.3、§5` 的字号与字重，没有任何"手写海报感"处理。

**修改**：
- 删除该句，改为"字体、字号、字重、颜色严格按源码"。
- **字体文件（需要你决定）**：原版用方正兰亭黑 Pro（`FZLTBlackProGlobal.ttf` / `FZLTBlackProGlobalHeavy.ttf`）。像素级一致必须用同一字体：
  - **有授权**：把这两个 ttf 一并交给 Gamex，按原版 `@font-face` 名 `FZLTRegular / FZLTHeavy` 加载。
  - **无授权**：两边统一回退为"微软雅黑 / 苹方"。这种情况下文字宽度会变，得分控件宽度、等级条宽度也会跟着变，验收时允许文字区域有偏差。
