幸运刮刮乐 · Roguelike 重构

用金币买卡 · 刮出收益 · 攒币升级 · 肉鸽增益 · 跌破 0 即破产
版本 v2 设计稿（待确认） 单人 Roguelike 经营/博彩 画布 920 × 460 宠物围观陪伴

1一句话定位

用金币购买不同等级的刮刮卡，刮出收益 → 攒够金币升级 → 解锁更高面值、更高风险的卡 → 每次升级获得肉鸽式增益 三选一 → 金币跌破 0 即破产结束。
攒金币、控风险、滚雪球。

2核心循环 Core Loop

开局（读取全局金币 / 等级 / 增益） ↓ 左侧商店选卡 → 扣金币购买 ↓ 中央刮卡（鼠标滑过刮开）→ 揭晓 ↓ 结算：余额 − 卡价 + 奖金 − 罚金 ├─ 金币达到等级阈值 → 升级 → 肉鸽三选一 → 解锁新卡 / 刮具 └─ 金币 < 0 → 破产 → 本局结束（记录最高金币 / 最大 jackpot） ↓ 继续买下一张 …
  • 金币是全局变量，跨局持久，升级不清空。
  • 等级一旦达成永久保留（金币回落也不降级）。

3数值总框架（RTP 设计）

风险张力来自：原始卡 RTP 接近或略低于 100%（缓慢失血），靠 肉鸽增益 + 刮具 把长期 RTP 拉到 100% 以上。玩得好滚雪球，贪心买不起的高风险卡就会被 💣 打穿破产。

8破产 / 风险机制（核心张力）

  • 金币流：净额 = 余额 − 卡价 + 奖金 − 罚金(💣/黑洞)
  • 购卡要求 余额 ≥ 卡价；但刮开后的 💣 罚金可把余额打到负。
  • 金币 < 0 → 破产 → 本局结束，结算页显示：最高金币纪录、最大 jackpot、总刮数。
  • 风险来源：低余额时贪买高风险卡，💣 串出就破产 → 玩家必须留缓冲金 / 用拆弹·保底刮具 / 攒护身符。
数值护栏：每张卡「最大可能罚金」在购买前显示，让风险可预期但仍刺激。

11额外好玩建议（可选模块）

手气连击条：连续中奖点亮 combo 槽，满槽触发「金运爆发」短暂全卡折扣或加倍。
宠物吉言 / 毒奶：刮前随机预言（"我觉得这张稳了！"），按 persona 有旺财有乌鸦嘴，命中/打脸都有反应。
神秘限定卡：商店偶现闪光「✨神秘卡✨」，专属美术 + 超高波动，限量 1 张。
图鉴 / 成就：收集刮到过的 jackpot 与稀有符号，集齐解锁隐藏刮具或皮肤。
每日首刮免费 + 每日折扣卡：高频回访钩子。
破产「最后一搏」：余额濒临 0 时，可抵押下一级解锁权换一张「绝地卡」，搏命翻盘。
诅咒 / 黑卡：高风险变体，全程 💣 更多但 jackpot 翻倍，给老玩家的硬核挑战。
金币滚动 + 数字跳动 + 金光彩纸：放大每一次「数字暴涨」的爽感（刮刮乐的灵魂）。
最高纪录排行（本地）：破产结算后展示历史最佳，激发再来一局。
