# 幸运刮刮乐 · Roguelike —— 像素级复刻规格书（平台无关）

> 目标：让任意平台/引擎（Unity / Cocos / Web / Flutter / 小程序…）按本文档实现出**视觉、交互、数值**完全一致的刮刮乐游戏。
> 配套文件：
> - `replica-spec.json` —— 机器可读数值（AI 优先消费这份）
> - `assets-manifest.json` —— 80 个素材的尺寸/透明通道/md5
> - `assets.zip` —— 素材包
>
> 所有数值均为**运行时实测/源码提取的最终值**，不要再自行推算。

## 1. 总览

单局循环：

```
选卡（购卡区） → 发牌 → 刮开（指针划过涂层） → 自动揭晓剩余 → 判定 → 结算
                                                      ↓
                              中奖/升级 → 可选：刮具解锁弹窗 → 三选一增益弹窗
```

核心区域（自然尺寸）：

| 区域 | 自然尺寸 | 说明 |
|---|---|---|
| 顶栏 HUD | 1560×56（随视口） | 得分 / 等级条 / 增益条 |
| 舞台单元 `#game` | 920×952 | 刮刮卡 800×800 + 间距 20 + 购入栏 812×120 |

## 2. 坐标系与自适应（关键：三条规则）

页面不做响应式重排，而是**整体等比缩放**。以下三条规则必须原样实现。

### 2.1 顶栏隐形边界（防「得分」压「等级条」）

顶栏为三列栅格：

```
[ 1fr (>= hud-side) ] [ 等级条 980，上限 ] [ 1fr (>= hud-side) ]
      左：得分控件              中：等级条              右：占位
```

- `hud-side = 得分控件实测宽 + 24`（实测得分控件宽约 149 → hud-side ≈ 173）
- 两侧同下限、同弹性 → 等级条永远居中，且永不与得分重叠
- 窄屏（视口宽 ≤ 720）：`hud-side` 下限降为 128，得分字号 26→20、数字 36→28

### 2.2 舞台单元（卡片 + 购入栏）

```
上占用 topOcc = max(顶栏底, 增益条底)      // 无增益 ~110，有增益 ~170
下占用 botOcc = vh − 状态条顶              // 状态条固定在底部 22
可用高 availH = vh − topOcc − botOcc − 32  // 上下各 16 安全边
可用宽 availW = vw − 2 × reserve
reserve      = min(刮具栏缩放后宽 + 50 + 24, vw × 0.28)

k_stage = min(1, availH / 自然高(952), availW / 自然宽(920))
偏移    = (topOcc − botOcc) / 2
transform = translateY(偏移) scale(k_stage)   // 变换原点：中心
```

### 2.3 刮具栏（独立缩放）

```
k_tools = min(1, availH / 592, (vw × 0.28) / 128)
top     = 可用区中心 − 592/2        // 垂直居中于可用区
right   = 50                        // 贴右边缘
transform = scale(k_tools)，原点中心
```

### 2.4 实测基准（用于验收）

| 视口 | k_stage | k_tools | 舞台顶~底 | 刮具栏顶~底 | 与卡片间隙 |

| 1258×900 | 0.735 | 1 | 130~899 | 180~772 | 157 |

## 6. 交互规格

### 6.1 刮卡

| 项 | 值 |
|---|---|
| 输入 | 指针按下（画布）→ 移动（window 级，支持甩出边界继续）→ 抬起 |
| 笔刷 | 圆形擦除，半径 ≈ 格子对角线的一半（实测格 105×101，符号 52×54） |
| 揭晓规则 | 划过的格子立即显示符号；刮到阈值后自动揭晓剩余全部 |
| 自动揭晓触发 | 已刮面积达阈值（源码 `Scratch` 内判定） |
| 刮具效果 | 水晶球：发牌时预揭中央格（index 4）；四叶草：开刮前移除 1 个坏符号 |
| 鼠标光标 | 刮卡时替换为当前刮具图标（SVG data URI 光标） |

### 6.2 按钮 / 键盘

| 操作 | 行为 |
|---|---|
| 点击已解锁槽 | 购买并发牌（扣金币） |
| 点击未解锁槽 | 不响应（灰态） |
| A / D | 购卡区上一页 / 下一页 |
| 1~5 | 选中对应刮具（点击刮具方框同效） |
| 点击刮具 | 已拥有→佩戴；未拥有→购买（若可购买） |
| 点击遮罩 / 知道了 | 关闭弹窗并进入下一个 |
| 弹窗打开时 | 屏蔽 A/D |
